# fsz

[English](README.md) · [项目总览](../../README.zh.md)

`fsz` 可以显示文件大小，也可以列出目录下各项的大小。

## 安装

按[项目安装说明](../../README.zh.md#安装)从源码或公开版本安装。公开版本发布后，只安装 `fsz` 的 npm 包时运行：

```sh
npm install -g @melonyrame/fsz
```

## 用法

在 workspace 根目录运行：

```sh
cargo run --locked -p fsz -- .
cargo run --locked -p fsz -- "path/to/file or directory"
```

不传路径时使用当前目录。目录表格只列出直接子项，但子目录大小包含扫描到的后代文件。

## 统计规则

- 统计的是逻辑字节数，不是磁盘实际分配的空间。指向同一文件的不同硬链接目录项分别计数。
- 显式传入符号链接时会解析其目标。递归扫描跳过符号链接和特殊文件。在 macOS 和 Linux 上不跨设备；在 Windows 上跳过目录重解析点，包括目录联接和卷挂载点。
- 扫描不是快照。若其他进程在检查与进入目录之间替换了目录，扫描边界检查可能不会覆盖替换后的目录。
- 大小前的 `~` 表示该项只统计到一部分。总计包含这类条目中已测得的字节数。
