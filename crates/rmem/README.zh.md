# rmem

[English](README.md) · [项目总览](../../README.zh.md)

`rmem` 是一个只读终端监视器，用于查看本机进程、物理内存和交换空间。每秒刷新一次，默认按进程驻留内存从高到低排序。

## 安装

运行以下命令，只安装 `rmem`。

```sh
npm install -g @melonyrame/rmem
```

其他安装方式见[项目安装说明](../../README.zh.md#安装)。

## 用法

在交互式终端中，从 workspace 根目录运行：

```sh
cargo run --locked -p rmem
```

| 按键 | 操作 |
| --- | --- |
| `q` | 从进程列表退出 |
| `↑` / `↓`、`k` / `j` | 选中上一个或下一个进程 |
| `gg` / `G`、`Home` / `End` | 选中当前列表中的第一个或最后一个进程 |
| `m` / `c` / `p` / `t` | 按内存、CPU 使用率、PID 或 CPU 时间排序 |
| `/` | 按 PID、用户、进程名或命令搜索 |
| `Enter` | 应用搜索或打开所选进程的详情 |
| `Esc` | 关闭详情或清除搜索 |
| `r` | 立即刷新 |

输入 `gg` 时，连按两次小写 `g`。两次按键之间不能按其他键，但没有时间限制。`gg` 和 `G` 只在浏览进程列表时生效，并遵循当前搜索结果和排序。

## 指标

- `MEM` 是进程驻留内存，在 Unix 上是 RSS，在 Windows 上是工作集。`MEM%` 是它占物理内存总量的比例；`ΔMEM` 是相对于上次刷新的变化量。
- 多核系统上的 `CPU%` 可以超过 100%。`TIME` 是累计进程 CPU 时间，不是进程已运行的时间。
- `COMMAND` 优先显示命令行，读不到时依次回退到可执行文件路径和进程名。
- 能看到哪些进程与指标取决于操作系统及权限。用户或内存百分比缺失时显示 `-`。物理内存或交换空间总量被报告为零时显示 `n/a`。采集后端不总能区分进程指标是实测值、不可用，还是上次采集的旧值。
- Windows 上的 `SWAP (EST.)` 根据系统提交量和物理内存估算交换空间用量和容量，不代表页面文件的实际占用。
